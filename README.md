# Site LocalInsta — GitHub Pages

Este diretório já é a versão estática publicada. Para atualizar o GitHub Pages do repositório, envie o conteúdo da pasta site/ para a raiz da branch main (substituindo os arquivos antigos).

O site usa caminhos relativos, portanto funciona em https://qg-digital.github.io/LocalInsta/. O botão de download aponta para a release 1.2.10 oficial.

Não é necessário instalar Node, React ou qualquer dependência para publicar esta pasta.
