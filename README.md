🚀 LocalInsta

Automatize as publicações do seu Instagram sem perder tempo entrando no
aplicativo todos os dias.

O LocalInsta é um aplicativo para Windows que publica automaticamente no
Feed e nos Stories a partir das imagens que você adiciona ao programa.

Você continua cuidando do seu negócio. O LocalInsta cuida das postagens.

------------------------------------------------------------------------

✨ Principais recursos

-   📷 Publicação automática no Feed e Stories.
-   📝 Geração automática de legendas a partir das imagens.
-   📅 Organização das publicações sem precisar abrir o Instagram
    diariamente.
-   💻 Funcionamento local, mantendo seus dados no próprio computador.
-   🔄 Recuperação automática das tarefas caso o computador seja
    reiniciado.

------------------------------------------------------------------------

🖼️ Como funciona

1.  Adicione suas imagens ao LocalInsta.
2.  Configure sua conta e suas preferências.
3.  Deixe o programa trabalhando em segundo plano.
4.  As publicações acontecem automaticamente.

------------------------------------------------------------------------

🔒 Privacidade

O LocalInsta foi desenvolvido seguindo uma abordagem Local First.

-   Suas credenciais permanecem no seu computador.
-   Não utilizamos servidores próprios para armazenar seus dados.
-   Você mantém o controle das informações da sua empresa.

------------------------------------------------------------------------

🤖 Legendas automáticas

Quando configurado, o LocalInsta utiliza modelos de IA para analisar as
imagens e criar legendas compatíveis com o estilo da sua marca,
reduzindo o trabalho manual na criação de conteúdo.
